# Security

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security-sensitive reports.

Prefer one of:

1. [GitHub Security Advisories](https://github.com/xPOGx/BlinkGuard/security/advisories/new) for this repository (private report)
2. Email the maintainer: [pavel19.1078@gmail.com](mailto:pavel19.1078@gmail.com)

Include steps to reproduce, affected version/OS, and impact. We will acknowledge reports as soon as practical and coordinate a fix before any public disclosure.
